# Скачанные бланки и нормативы (рабочие копии)

Скачано 2026-10-07 с разрешения владельца репозитория, только с двух сайтов и только форматы DOCX, DOC, PDF, XLSX:

- `stroykadoc.ru` (папка `stroykadoc/`, 31 файл, старые формы РД-11-02-2006 и РД 11-05-2007, образцы заполнения);
- `stroydoc-abv.ru` (папка `stroydoc-abv/`, 334 файла, формы по 344/пр, СП 70 и прочее).

**Это копии коммерческих сайтов, а не официальные публикации.** Для эталона форм сверять с официальными текстами (pravo.gov.ru, ГАРАНТ, КонсультантПлюс). Файлы нужны для разработки и тестов, в git не коммитить (≈100 МБ).

## Проверки безопасности

- Только HTTPS и два перечисленных домена.
- Проверка сигнатуры: PDF (`%PDF`), DOCX/XLSX (ZIP, без `vbaProject`, встроенных объектов, ActiveX, исполняемых файлов), DOC (OLE, без маркеров макросов). PDF с JavaScript, `/Launch`, `/OpenAction` и вложениями отклонялись (отклонён 1 файл: `sp77-akt-osvidetelstvovaniya-skrytyh-rabot.pdf`).
- Размер ≤ 8 МБ.
- Проверка Microsoft Defender (Custom Scan папки): угроз не найдено.
