# Этап 1. Вход и объекты

Код продукта ещё не написан. Этот этап закрывает вход, личный кабинет и CRUD строительных объектов. Пакеты, документы, очереди, OCR и отчёты сюда не входят.

Фуллстек на этом этапе задачи не берёт: он занят репозиториями на GitHub. Остальные не создают второй репозиторий и не меняют стек. Каркас, который он отдаст, ожидается таким:

- `apps/api` — NestJS
- `apps/web` — React, Vite, TypeScript
- PostgreSQL и Redis через Docker Compose

Пока каркаса нет, можно готовить модули локально по контракту ниже, но вливать их только в его репозиторий.

## Контракт

- `openapi/openapi.yaml`, операции Auth, Employees и Objects, включая `/employees`, `/object-types`, `/work-types`, `/counterparties`, `/objects/{id}/status`
- `prisma/schema.prisma`
- `AI-PTO_Project_Documentation_v0.2.md`, разделы про роли, сессию и статусы объекта

Сессия — cookie `ai_pto_session`, HttpOnly, Secure, SameSite=Lax. Токен в localStorage не хранится. Запросы браузера идут с `credentials: "include"`.

Роли этапа: `owner` и `engineer`. `engineer` — только просмотр; все мутации (создание, правка, архивация) — только `owner`. Подрядчик в систему не входит.

## Маршруты кабинета

| Путь                | Экран           | Кто        |
| ------------------- | --------------- | ---------- |
| `/login`            | Вход            | Фронтенд 1 |
| `/`                 | Обзор           | Фронтенд 1 |
| `/profile`          | Профиль         | Фронтенд 1 |
| `/objects`          | Список объектов | Фронтенд 2 |
| `/objects/new`      | Создание        | Фронтенд 2 |
| `/objects/:id`      | Карточка        | Фронтенд 2 |
| `/objects/:id/edit` | Редактирование  | Фронтенд 2 |

Пункты меню «Документы», «Замечания», «Комплектность» и «Отчёты» на этом этапе не показываются.

## Готово, когда

Инженер открывает `/login`, входит сидовой учёткой, видит обзор своей организации, создаёт объект, меняет его, переводит в `active`, а владелец архивирует. Чужой объект по прямому id возвращает 404. Выход очищает cookie, обновление страницы без сессии возвращает на `/login`.
